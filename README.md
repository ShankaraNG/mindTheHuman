## Setup

The cleaning scripts in `src/clean/` expect the raw data at `dataset/` in the project root, split into the four subfolders below. Exact names matter — the scripts build paths from these directly.

```
mindTheHuman/
├── dataset/
│   ├── 1_recommendation_bank/
│   │   ├── deck_benchmark_bands.csv
│   │   ├── deck_current_cover.csv
│   │   ├── deck_limit_benchmarks.csv
│   │   └── deck_recommendations.csv
│   ├── 2_book_of_business/
│   │   ├── recorder_book_of_business.csv
│   │   └── recorder_cover_lines.csv
│   ├── 3_company_context/
│   │   ├── healthcheck_questionnaire.csv
│   │   └── hubspot_company_context.csv
│   └── 4_evaluation/
│       └── synthetic_prospect_briefs.csv
├── src/
│   └── clean/
└── data/          # generated by the scripts below, gitignored
```

`dataset/` is not committed (see `.gitignore`) — copy it into the project root before running anything.

### Running the pipeline

Run everything at once:

```bash
python src/clean/run_all.py
```

Or run scripts individually:

```bash
python src/clean/clean_recorder.py
python src/clean/clean_company_context.py
python src/clean/clean_benchmark_bands.py
python src/clean/clean_client_cover_summary.py
python src/clean/clean_synthetic_briefs.py
python src/clean/clean_recommendations.py
python src/clean/parse_deck_current_cover.py
python src/clean/parse_deck_limit_benchmarks.py
python src/clean/assert_join_integrity.py   # verifies everything joined correctly
```

Each script reads from `dataset/` and writes its cleaned output to `data/`.
