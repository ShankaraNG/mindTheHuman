# Eval harness — real sentence embeddings fallback for theme matching.
# Runs in its own subprocess (src/evaluation/embeddings_worker.py) — NOT
# a stylistic choice, it routes around a real bug: importing profile.
# normalise anywhere in this project overwrites sys.modules['profile']
# with our src/profile/ package, shadowing Python's stdlib profile module.
# transformers 5.x's internal `import cProfile` -> `import profile` then
# breaks several layers deep with a misleading "Could not import module
# 'PreTrainedModel'" error. A subprocess has its own sys.modules, so this
# works there. Confirmed working on Python 3.11, confirmed NOT working
# in-process on Python 3.14. If sentence-transformers fails to install or
# the worker fails to load the model, the eval harness still runs fine on
# vocabulary matching alone — see semantic_match.py's own docstring.
sentence-transformers
